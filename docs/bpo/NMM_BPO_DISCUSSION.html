PLN Network Model Management1
Kenapa direalign

PoC membuktikan jalur CIM ke PowerFactory, tetapi belum membuktikan model bisa dibangun dan dipelihara dari data PLN existing.

Sudah terbukti

ED/CIM interchange, external simulation path, dan result/state round-trip.

Belum terbukti

Identity reconciliation, asset-to-function mapping, topology aktual, governance, update, dan maintenance burden.

Technology-path proof ≠ production-feasibility proof2

Scope MVP

Input per GI, review per bay, publish per GI.

INPUT

1 cleaned GI asset extract + 1 GI SLD.

REVIEW

Exception/ambiguity per bay.

OUTPUT

Canonical GI graph + SLD + CIM + report.

Per-bay terlalu sempit untuk konteks busbar/coupler; raw bulk terlalu luas untuk MVP karena bercampur dengan enterprise cleansing.

Bulk nanti: staging → per-GI job splitter.4
Boundary data

  • GI scope

  • source provenance

NMM yang menyelesaikan

  • functional grouping
  • PMS/PMT/ES role
  • equipment sequence
  • Terminal/ConnectivityNode

  • readiness

Data request ke BPO

Yang diminta hanya dua evidence set untuk satu GI.

1. Cleaned asset extract

ASSETNUM, SITEID, GI, LOCATION/bay, ASSETTYPE, description, NIA/TECHIDENTNO bila ada, phase bila ada, source revision.

2. Corresponding SLD

Full primary GI SLD, revision/date jelas, approved/as-built jika tersedia, label dan primary equipment terbaca.

Tidak meminta BPO menambahkan Terminal, ConnectivityNode, PMS role, XY, impedance, P/Q, atau relay setting untuk pilot pertama.

Minimum request, maximum feasibility signal.9

Decision request

Untuk memulai, BPO cukup memilih satu GI dan memberikan dua evidence set.

Data

Cleaned asset extract + corresponding SLD/revision.

People

Source owner + satu engineering reviewer untuk exception review.

Governance

Pilot Network Model Owner + handling/security constraint.

Decision after pilot

Scale, improve upstream data first, atau re-scope/stop.

Tujuan pilot bukan membuktikan bahwa XML bisa dibuat. Tujuannya membuktikan bahwa model jaringan bisa dibangun dan dipelihara dengan effort yang layak.
