Apa yang PoC 2025 sudah buktikan

Pipeline teknis bisa jalan — tetapi feasibility NMM skala PLN belum terbukti.

Sudah dibuktikan

  • ED dapat diterjemahkan ke CIM/XML.
  • Model yang sudah dilengkapi dapat diimpor ke PowerFactory.
  • Load flow dapat dijalankan.
  • State Variable dapat dibaca kembali ke NMM.

Belum di-de-risk

  • Asset → functional equipment mapping.
  • Topologi CB/PMS/bay aktual.
  • Rekonstruksi dari data existing tanpa re-entry besar.
  • Governance perubahan dan owner model.
  • Maintenance model pada skala nasional.

Evidence: laporan PoC mengakui missing distinct indicator untuk CB/DS, generator, trafo dan line; parameter teknis dan layout juga masih memerlukan pelengkapan manual.

PoC adalah technology-path proof, bukan production-feasibility proof.2
Masalah data yang sebenarnya

Asset register menjawab “apa yang dimiliki”; network model menjawab “bagaimana semuanya terhubung”.

Asset

ASSETNUM, NIA, TECHIDENTNO, manufacturer, install date, location, lifecycle.

Topology

Equipment role, Terminal, ConnectivityNode, bus selection, line/transformer endpoint.

State

Normal/open state, actual operating state, load/generation snapshot, scenario.

Nilai bisnis sebelum CGMES eksternal

NMM tetap berguna meskipun pertukaran daya lintas sistem masih jauh.

Hari ini

  • mengurangi re-entry model engineering;
  • satu baseline untuk SLD dan studi;
  • traceability asset ↔ network object;
  • change impact lebih terlihat;
  • data gap dan conflict eksplisit.

Nanti

  • PowerFactory / PSS®E / ETAP base case;
  • EMS/SCADA model alignment;
  • protection context dan outage analysis;
  • CGMES package exchange;
  • cross-utility / cross-border exchange bila diperlukan.
External CGMES exchange is one use case, not the only reason NMM exists.6

Security by design

SSOT harus update, tetapi tidak harus terbuka.

Access

PLN-controlled deployment, RBAC, least privilege, model-scope authorization.

Integrity

Immutable raw evidence, versioned releases, audit log, explicit reviewer/approver.

Integration

Read-only source connectors by default; no silent write-back; encrypted service credentials.

Draft, reviewed, dan published model harus dipisahkan. Setiap export downstream membawa model version yang dapat ditelusuri.

Secure provenance is part of the data model, not an afterthought.9

Repo reengineering

Arahkan repo dari “workbook → XML” menjadi “evidence → canonical graph → publish”.

Pertahankan

  • Babel intake + provenance.
  • CIM round-trip kernel.
  • validation/profile checks.
  • review XML & viewer concepts.
  • explicit assumption handling.

Ubah prioritas

  • workbook menjadi adapter, bukan database utama;
  • SLD menjadi topology evidence;
  • review exception-only;
  • XY menjadi presentation override;
  • canonical graph menjadi pusat domain.

Decision request

Apa yang perlu diputuskan BPO sebelum NMM diskalakan?

Mandate

Apakah PLN membutuhkan satu published network model lintas asset, operation, engineering dan study tools?

Ownership

Siapa Network Model Owner dan siapa steward setiap domain?

Pilot

Setujui satu GI real sebagai feasibility test: asset register + SLD, minimum re-entry.

Go / no-go

Scale hanya jika automation, review burden, data quality, security, dan downstream value terukur.

Target akhir bukan “punya aplikasi NMM”. Target akhirnya adalah semua studi dan aplikasi menggunakan model jaringan yang sama, terbarui, terlacak, dan dapat dipercaya.
